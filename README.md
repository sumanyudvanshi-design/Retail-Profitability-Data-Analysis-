# Retail Business Performance & Profitability Analysis

An end-to-end data analytics project exploring structural supply chain inefficiencies. This project identifies a clear negative correlation between product shelf-time and net financial margins using Python for statistical analysis and Power BI for executive dashboard visualizations.

## 📁 Project Repository Structure
* **`retail_data.csv`**: Automated 1,000-row simulated retail transaction dataset containing custom profit variations, seasonal markers, and inventory shelf-life attributes.
* **`Retail_Performance_Analysis.pbix`**: Interactive Power BI dashboard complete with user-controlled slicers, dynamic KPI cards, structural bar charts, and transactional regression scatter plots.
* **`Retail_Performance_Analysis.pdf`**: Completed two-page formal project documentation and strategic summary report.

## 📊 Core Analytical Findings
* **Statistical Insights:** Discovered a strong **negative correlation coefficient of -0.6842** between product shelf-time (`inventory_days`) and transaction net profit.
* **Profit Drains:** Isolated **Footwear** as the single highest loss-generating category with a baseline structural margin of **-6%**.

## 💡 Strategic Recommendations
1. **Inventory Liquidation:** Deploy immediate retail price markdowns (e.g., 20% drops at 60 days) and dynamic product bundling strategies for the underperforming Footwear line.
2. **Procurement Adjustments:** Shift bulk purchase ordering to an automated Just-In-Time (JIT) replenishment model triggered dynamically by specific regional sales velocity markers.
